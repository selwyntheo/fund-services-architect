PLANE 1 · EXPERIENCE & SUPERVISION

Human Experience & Supervision Plane

— one workbench for working with agents; one console for governing them

Ops Workbench analysts

  • Task queue blended: human tasks + agent drafts awaiting review
  • Side-by-side evidence panel: agent reasoning, sources, ACCEL-DSL rule hits
  • Accept / edit / reject — every edit is captured as a labeled correction

Approval Queue T2/T3 gates

  • Confidence, materiality & blast-radius shown per item; SLA timers
  • Four-eyes routing for T3 (NAV release, filings, cash movement)
  • Approval mints a signed, time-boxed approval token the agent must present

Supervisor Console HOTL

  • Live autonomy dashboards: acceptance rate, escalations, drift alerts
  • Per-agent pause / throttle / kill switch; tier demotion on anomaly
  • Replay any run from the immutable audit trail

Client & Oversight Views read-only

  • Explainability pack per NAV / filing: who (human+agent), what, why
  • Regulator-ready evidence export from audit envelope
